BK Smart Parking System

Integrated demo menu. All modules now use the same shared SPMS database through shared/spms-db.js, so payment, occupancy, exit checkpoint, signage, and admin logs stay connected.

Tip: open modules in multiple tabs to see shared state updates.
M1

Scheduler & Queue

Create vehicle entry requests and assign slots when queued processes finish.
M2

Exit Checkpoint

Validate card/ticket/plate, block unpaid exits, open gate, and free occupied slots.
M3

Billing App

Pay the active parking session using the shared BKPay wallet.
M4

Occupancy Signage

Live signage screen powered by the shared parking slot data.
M5

IoT Occupancy Dashboard

Toggle sensor slots and load parking scenarios into the shared database.
M6

Core System & Admin

Manage fee policy, permissions, signage preview, and system logs.
